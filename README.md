# CS330---Comp-Graphic-and-Visualization
Working on this project helped me develop a better understanding of how important planning and organization are when designing software. When creating my 3D kitchen countertop scene, I had to consider how each object would look, what basic shapes could be used to construct it, and how the objects would fit together to create a realistic environment. I learned how to break down complex objects into smaller components and use transformations such as scaling, rotation, and positioning to get the appearance I wanted.
I took an incremental approach to the design process, which allowed me to learn new concepts gradually and build on what I learned throughout the course. After creating the objects in my scene, I focused on improving their appearance through texture mapping and lighting adjustments. Working on one component at a time helped me understand how the individual pieces came together to create the final scene.
While developing my 3D scene, I learned how to use the provided code and basic shapes to create objects that resembled real kitchen appliances and accessories. I adjusted their size, rotation, and position to make the scene look more realistic. I also worked with textures and lighting to improve the appearance of different materials.
Iteration was an important part of my development process. I regularly made changes, ran the program, and checked the results. Some objects required several adjustments to their positioning and rotation, while the lighting and shadows also needed fine-tuning. This taught me that developing a program takes patience and that testing different solutions is often necessary.
Throughout the milestones, I became more comfortable making changes to the code and troubleshooting problems. I learned to focus on one issue at a time and build on what I had already completed. In future projects, I can use these strategies to solve problems more efficiently and make steady progress toward completing my work.
This project helped me develop skills that I can use as I continue my education in computer science and software engineering. I gained experience with 3D objects, transformations, textures, shaders, and lighting. I also learned how mathematical concepts are used to position objects and create realistic scenes. I can build on these skills in future courses involving graphics, simulations, and interactive applications.
